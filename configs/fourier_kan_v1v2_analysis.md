# Fourier-KAN T60 Head：v1→v2 迭代与损失函数交互分析

## 1. 背景

CMGAN backbone 输出特征经池化后送入回归 head 预测 T60。原始 MLP head 使用 ReLU 激活，表达能力受限于分段线性。Fourier-KAN 用三角函数基替换线性层，理论上对非线性映射拟合能力更强。

FourierKAN 层的核心参数 **Ω（num_frequencies）** 控制每个激活函数的 Fourier 频率数：

```
φ(x) = Σ_{w=1}^{Ω} [ a_w·cos(wx) + b_w·sin(wx) ]
```

Ω 越大，可拟合的非线性越复杂，参数量也越多。

## 2. v1→v2 更新原因

v1 所有 KAN 层统一使用 Ω=4，但不同层职责不同：

- **第一层**（64→32）：接收 64 维池化嵌入，非线性结构复杂，Ω=4 可能表达力不足
- **隐层**（32→16）：特征已被压缩，维度小，无需过大 Ω

参考 Fourier-ASR 的分层 grid size 设计，v2 将首层与隐层的频率数解耦：

| | v1 | v2 |
|---|---|---|
| 第一层 Ω | 4 | **16** |
| 隐层 Ω | 4 | **8** |
| KAN head 参数量 | ~33K | ~86K |
| 投影层 | Linear + Tanh + LayerNorm | Linear + LayerNorm（移除 Tanh） |

## 3. 实验结果

| 实验 | Ω 配置 | 损失函数 | avg RMSE(ms) | avg MAE(ms) | avg R² | avg r |
|------|--------|----------|-------------|------------|--------|-------|
| kan_v1_mae | 全4 | MAE | 114.84 | **67.59** | 0.8857 | 0.9414 |
| kan_v1_mse | 全4 | MSE | 116.82 | 71.46 | 0.8815 | 0.9397 |
| kan_v2_mae | 16/8 | MAE | 118.24 | 70.57 | 0.8790 | 0.9379 |
| kan_v2_mse | 16/8 | MSE | **111.15** | 72.40 | **0.8931** | **0.9484** |

对照基准（MLP head）：avg MAE=65.5ms，avg RMSE=113.1ms（MAE loss）

## 4. 结果分析

### 4.1 两个交叉现象

- **同版本内**：v1 中 MAE loss 全面优于 MSE loss；v2 中 MSE loss 在 RMSE/R²/r 上优于 MAE loss
- **同 loss 内**：Ω 增大后，MAE loss 效果变差（67.59→70.57），MSE loss 效果变好（116.82→111.15）

### 4.2 核心解释：容量与梯度信号的匹配

FourierKAN 的高频分量需要**强且有方向的梯度**来约束，而两种 loss 的梯度特性不同：

- **MAE loss**：梯度 = sign(ŷ - y)，大小恒为 1，与误差大小无关
- **MSE loss**：梯度 = 2(ŷ - y)，大小与误差成正比

| | MAE loss（梯度均匀±1） | MSE loss（梯度∝误差大小） |
|---|---|---|
| **Ω=4 低容量** | ✓ 匹配：模型只学平滑映射，均匀梯度刚好够用，不因少数大误差样本歪曲整体 | ✗ 不匹配：强梯度要求修正大误差，但低容量模型无法针对性修正，只能扭曲整体函数迁就异常值 |
| **Ω=16/8 高容量** | ✗ 不匹配：高频分量得到的梯度信号太弱太均匀，多余自由度无法被有效约束，过拟合噪声 | ✓ 匹配：强梯度明确指引高频分量修正大误差，额外容量被有效利用 |

**原则：模型容量越高，越需要误差敏感型损失来驾驭额外自由度；容量越低，越需要鲁棒型损失避免力不从心的修正。**

### 4.3 v2 + MSE 的 bias 问题

v2_mse 虽然 RMSE/R² 最优，但出现严重系统性高估（avg Bias=+26.4ms）。原因是 v2 更大的 Ω 使 KAN 非线性更强，MSE 的二次梯度将模型推向训练集均值方向，形成正偏移。MAE loss 的常数梯度规避了此问题（avg Bias≈-5ms）。

## 5. 后续改进的递进逻辑

v2 + MAE 的实验结果暴露了两个问题，后续改进逐步解决：

```
v1_mae → v2_mae → v2_mae_clip1 → v2_mae_clip1_log
MAE=67.59  MAE=70.57  MAE=65.3        MAE=62.1
```

| 步骤 | 解决的问题 | 机制 |
|------|-----------|------|
| v1→v2 | Ω 太小表达力不足（但引入了新问题） | 首层 Ω=16 增强非线性拟合能力 |
| +clip | v2+MAE 下高频分量梯度不稳定，14 epoch 早停 | 梯度裁剪稳定训练，延长有效训练期 |
| +log | 线性归一化下高 T60 区间训练信号弱，系统性低估 | log 变换均衡各 T60 区间的梯度贡献 |

**加 clip**：v2 参数量是 v1 的 2.6 倍，Fourier 高频分量梯度易出现尖峰，导致 v2_mae 仅 14 epoch 就触发早停（v1_mae 24 epoch，MLP 44 epoch）。clip_grad_norm=1.0 稳定了训练过程，使模型有机会充分收敛，MAE 从 70.57 降至 65.33。

| 指标 | kan_v2_mae | kan_v2_mae_clip1 | 变化 |
|------|-----------|-----------------|------|
| avg RMSE | 118.24 | 112.91 | -5.33 |
| avg MAE | 70.57 | 65.33 | -5.24 |
| avg R² | 0.8790 | 0.8895 | +0.0105 |
| avg r | 0.9379 | 0.9433 | +0.0054 |

clip 对 MAE loss 明确有效，四个指标全面且大幅提升。MAE 的正常梯度只有 ±1，但高频分量参数多、耦合复杂，偶尔会产出范数远超正常的梯度向量，导致单步参数更新过大，把模型推到 loss 坏区触发早停。clip 限制这种异常步，让训练平稳跑完。本质上 clip 对 MAE 解决的不是"梯度方向对不对"的问题，而是"训练能不能跑完"的问题。

**加 log**：线性归一化下各 T60 区间在 label 空间等宽，但高 T60 区间绝对误差天然更大，模型倾向低估高 T60（各实验 bias 均为负）。log 归一化使各区间等比例分布，均衡梯度贡献，MAE 从 65.3 降至 62.1。

三步改进是串行依赖的：v2 引入的容量问题需要 clip 来稳定训练，clip 稳定后才能看到 log 归一化的增益。

## 6. 小结

- Fourier-KAN v1/v2 在线性归一化 + MAE loss 下均未超过 MLP 基准
- Ω 与损失函数存在交互效应，简单增大 Ω 不一定带来提升，需匹配损失函数的梯度特性
- MAE loss 恒产生负 bias（低估），MSE loss 恒产生正 bias（高估），这是损失函数的固有性质（MAE 最小化中位数，MSE 最小化均值），与模型架构无关
- Gradient clipping 对 MAE 和 MSE 效果相反：clip 对 MAE 是"去噪"（削掉梯度尖峰，稳定训练），对 MSE 是"去信号"（削弱大误差样本的强梯度，而这正是 MSE 驾驭高容量的关键机制）。本质区别在于 clip 改变了样本间的相对影响力——正常样本不受影响，大误差样本的梯度被压到阈值，等于在关键时刻削弱了它们的话语权
- 逐步解决 v2 引入的训练不稳定和 label 空间分布问题后，v2_mae_clip1_log 取得当前最佳结果 avg MAE=62.1ms
