# 三条实测 RIR：主结果方法对比

沿用R13、R47、R61及全部43条语音（13/19/11条），不因预测效果更换案例或删样本。比较BERP、noise-aware、DAMTL、论文主表单任务Fourier-KAN和Ours，共215条已有预测。这里单任务不是参数量匹配MLP。

十份本地存档各1080行且样本名唯一，按(split,sample_name)连接；所选43条的历史T60、SNR逐条一致，预测齐全有限。Ours的43条预测与上一版逐条一致。全部误差由预测减参考标签重算，不使用存档Error_ms。

参考noiseaware §5.2图4，上排毫秒误差，下排相对误差百分比。箱须为最小值和最大值，箱体为25-75百分位，横线为中位数，菱形为均值。圆点/三角形分别表示Test2/Test4，所有样本均展示。无凹口、无显著性标记、无SNR重加权。

plot_data.csv保存215行绘图数据，summary_metrics.csv保存15行分组指标，plot_manifest.json保存来源、存档版本及哈希、口径与连接核验。逐样本存档舍入精度及已有历史版本限制继续适用。

这组图服务于主方法与对比基线的案例分析；参数量匹配MLP三模型图保留在上一独立输出目录，其比较目的属于消融分析。不同案例的语音/SNR/测量配置不同，不据此单独解释T60或模型机制。

仅新增本目录的派生结果。没有修改论文、标签、模型、输入存档、旧图或共享代码，未进行模型推理、训练、音频处理及新数据合成。
