# 三条实测 RIR 案例误差箱线图

使用此前按元数据固定的 R13、R47、R61，合并其 Test2 与 Test4 的全部 43 条语音。三模型各 43 条，共 129 条存档预测，未筛掉任何样本，未按 SNR 重加权。

上图为有符号毫秒误差，下图为除以各案例历史参考 T60 的有符号百分比误差。统一采用预测减历史参考标签，正值高估、负值低估。参考 noiseaware §5.2 图4，箱须为最小值和最大值，箱体为第25至75百分位，横线为中位数。叠加全部样本点（圆形Test2、三角Test4）及均值菱形。不使用箱体凹口或显著性标记。每个案例的参考标签固定，因此相对误差面板是同一分布的比例缩放。

R13 AIR meeting：0.303s，13条（Test2=7、Test4=6）。

R47 AIR lecture：0.697s，19条（Test2=9、Test4=10）。

R61 AIR stairway：1.133s，11条（Test2=6、Test4=5）。

三个模型为 dropout0.1 参数量匹配MLP单任务、dropout0.1 参数量匹配MLP多任务及KAN多任务，多任务均b005、seed42。预测沿用已有存档，保存精度的限制仍然适用。跨案例的语音、SNR和测量配置不同，本图描述固定RIR案例，不把跨案例差异单独归因于T60或宣称显著性。

plot_data.csv 为129行逐模型绘图数据；summary_metrics.csv 为9行指标及五数概括；plot_manifest.json 保存来源路径、输入哈希、选择及绘图口径。plot_cases.py 为可重现脚本。仅新增本目录产物，未修改论文、输入CSV、历史标签、配置、模型或已有结果；无推理、训练及音频处理。
