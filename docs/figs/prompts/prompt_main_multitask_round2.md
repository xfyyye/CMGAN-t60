## 如果第二轮飘移了怎么办

ChatGPT image-edit 偶尔会在"局部修改"时把无关元素也微调一下（字体重排、对齐偏移、颜色饱和度漂移）。**判断标准**：把第一版和第二版叠在一起肉眼对比关键区域。

如果飘移可接受（颜色偏一点、间距偏一点） → 直接收。

如果飘移严重（标签错字、维度数字变了、Mask Decoder 砖块数对不上） → 第三轮发：

```
你在第二轮把 [描述具体飘移点, 比如 "Mask Decoder 的 DilatedDenseNet
砖块从 6 块变成 4 块"] 改坏了。请回到第二轮的状态, 把这一处复原到第一版
的样子, 同时保留第二轮的改动 A 和改动 B。
```
