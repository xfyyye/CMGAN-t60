### 2. 梯度冲突相关工作（二选一，佐证"任务梯度冲突已被广泛研究"）

**候选 A（首选，与本文梯度余弦分析最相关）：**
- 作者：Tianhe Yu, Saurabh Kumar, Abhishek Gupta, Sergey Levine, Karol Hausman, Chelsea Finn
- 标题：Gradient Surgery for Multi-Task Learning（即 PCGrad）
- 年份：2020
- 渠道：NeurIPS 2020（Advances in Neural Information Processing Systems 33）
- arXiv：**2001.06782**（待核实）
- 核心贡献一句话：提出当任务梯度方向冲突（余弦相似度为负）时，将梯度投影到彼此法平面上以消除冲突分量
- **为什么相关：** 本文用梯度余弦相似度分析证明两任务"近似正交、无系统性冲突"，正好呼应 PCGrad 关注的"冲突梯度"问题——但本文场景中冲突并不存在，故无需 PCGrad 式的手术

**候选 B（备选，任务权重相关）：**
- 作者：Zhao Chen, Vijay Badrinarayanan, Chen-Yu Lee, Andrew Rabinovich
- 标题：GradNorm: Gradient Normalization for Adaptive Loss Balancing in Deep Multitask Networks
- 年份：2018
- 渠道：ICML 2018
- arXiv：**1711.02257**（待核实）
- 核心贡献：通过归一化各任务梯度幅度来自适应平衡多任务损失权重
- **为什么相关：** 本文用 EMA 归一化损失 + 任务权重消融，与 GradNorm 的"平衡任务梯度幅度"动机相通
