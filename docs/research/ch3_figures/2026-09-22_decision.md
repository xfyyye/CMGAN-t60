## Code audit (2026-09-22)
- Main config uses `TSCNet_KAN_MultiTask_2TSCB`, `n_tscb: 2`, and `t60_head_type: fourier_kan`.
- `DenseEncoder.forward`: `conv_1 (Conv2d -> InstanceNorm2d -> PReLU) -> DilatedDenseNet(depth=4) -> conv_2 (Conv2d stride in frequency -> InstanceNorm2d -> PReLU)`.
- `TSCB.forward`: reshape by frequency -> time Conformer + residual -> reshape by time -> frequency Conformer + residual -> restore `(B,C,T,F)`.
- `FourierKANLayer`: per-output/per-input/per-frequency trainable cosine and sine weights; computes a sum over input features and Fourier frequencies. The active head is projection + LayerNorm -> two FourierKAN layers (64->32->16, each LayerNorm + Dropout) -> Linear -> Sigmoid.
- `MaskDecoder.forward`: DilatedDenseNet -> sub-pixel frequency upsampling -> Conv2d -> InstanceNorm2d + PReLU -> final Conv2d -> `prelu_out`. Thus Mask Decoder does have a final PReLU output activation.
- `ComplexDecoder.forward`: DilatedDenseNet -> sub-pixel frequency upsampling -> InstanceNorm2d + PReLU -> final Conv2d to two channels. There is no activation after the final complex Conv2d.
- Main 2-TSCB forward order: magnitude/phase extraction and `[mag, real, imag]` concatenation -> DenseEncoder -> TSCB_1 -> TSCB_2 -> T60 head and the two denoise decoders. Magnitude-mask and complex residual are recombined before the model returns; `torch.istft` is applied outside the model in training/evaluation code.
- The `T60HeadFourierKAN` docstring still says “LayerNorm + Tanh”, but the implementation explicitly has no Tanh. Figures must follow the implementation, not that stale docstring.
