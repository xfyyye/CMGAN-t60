# FourierKAN application figure reference
URL: https://pmc.ncbi.nlm.nih.gov/articles/PMC13324552/

The paper reports a basic FourierKAN architecture and defines each edge function as a Fourier-series-like combination of basis functions with learnable coefficients. It is a secondary application paper, so it is useful for the visual idea (basis functions -> coefficient-weighted sum), not as the sole methodological authority.

Use only the basis-expansion convention; do not copy application-specific blocks.
