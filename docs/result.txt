# T60 估计对比结果（T60_Dataset_v7，test1–test4 + 平均）

单位：RMSE / MAE = ms；r = Pearson 相关系数；R² = 决定系数。
所有方法均在 T60_Dataset_v7 上以相同 train/eval/test1–4 划分训练与评估。
"平均" 为 test1–test4 的算术平均。

## 主对比（盲 T60 估计方法）

| 方法 | test1 RMSE/MAE/r/R² | test2 | test3 | test4 | 平均 RMSE/MAE/r/R² |
|---|---|---|---|---|---|
| BERP (Wang 2025) | 142.65 / 94.36 / 0.9165 / 0.8244 | 154.73 / 99.61 / 0.8994 / 0.7907 | 150.91 / 98.74 / 0.9032 / 0.8043 | 159.44 / 100.60 / 0.8950 / 0.7808 | 151.93 / 98.33 / 0.9035 / 0.8001 |
| noiseaware (Zheng 2022) | 129.50 / 80.85 / 0.9255 / 0.8559 | 128.80 / 83.87 / 0.9260 / 0.8569 | 130.92 / 78.65 / 0.9223 / 0.8501 | 145.44 / 86.16 / 0.9046 / 0.8177 | 133.66 / 82.38 / 0.9196 / 0.8451 |
| DAMTL (Zhang 2024) | 140.08 / 85.95 / 0.9125 / 0.8307 | 154.20 / 94.49 / 0.8934 / 0.7950 | 136.12 / 85.57 / 0.9179 / 0.8408 | 125.38 / 78.27 / 0.9299 / 0.8625 | 138.94 / 86.07 / 0.9134 / 0.8323 |
| 单任务 KAN（消融基线，kan_v2_mse） | 105.93 / 68.76 / 0.9537 / 0.9032 | 111.62 / 73.01 / 0.9461 / 0.8926 | 113.91 / 75.53 / 0.9477 / 0.8885 | 113.14 / 72.31 / 0.9462 / 0.8881 | 111.15 / 72.40 / 0.9484 / 0.8931 |
| **本文 w_denoise（α=1.0, β=0.1）** | 98.06 / 57.48 / 0.9576 / 0.9170 | 101.98 / 60.44 / 0.9550 / 0.9103 | 91.91 / 59.21 / 0.9636 / 0.9274 | 93.70 / 57.62 / 0.9612 / 0.9232 | **96.41 / 58.69 / 0.9594 / 0.9195** |

> 主结论：本文 w_denoise 平均 RMSE 96.41 ms，相比单任务消融基线（111.15 ms）降低 **13.3%**，
> 并显著优于 BERP（151.93）、DAMTL（138.94）、noiseaware（133.66）。

## 回归头消融（单任务下，Fourier-KAN 头 vs MLP 头）

| 配置 | T60 head 参数 | 总参数 | 平均 RMSE / MAE / r / R² |
|---|---|---|---|
| 单任务 + MLP 头（single_t60_mlp_mse） | 33,025 | 808,449 (0.81M) | 113.08 / 69.99 / 0.9439 / 0.8890 |
| 单任务 + Fourier-KAN 头（single_t60_kan_v2_mse） | 86,369 | 861,793 (0.86M) | 111.15 / 72.40 / 0.9484 / 0.8931 |

> 现有数据下 Fourier-KAN 头在 RMSE / r / R² 上均优于 MLP 头。
