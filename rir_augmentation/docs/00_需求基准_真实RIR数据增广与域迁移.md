# 真实 RIR 数据增广与域迁移

## 核心诉求（已确认）

**根本目标：解决 T60 估计模型从"仿真 RIR 域"到"真实 RIR 域"的迁移问题，使模型在真实房间环境下的 T60 估计精度逼近生产落地要求。**

用户最初设想是"借用毕业论文里 GAN 数据增广的方法扩充真实 RIR 数据"，经一轮澄清后确认：
- 真问题不是"如何用 GAN 造数据"，而是**仿真→真实的域迁移（domain shift）**。
- 直接用 GAN 生成 RIR 存在根本性技术错配（详见"已排除方案"），已被否决为伪需求。
- 正确方向：在"保证 T60 标签物理正确"的前提下，扩充真实 RIR 的多样性/数量，或缩小域间差距。

## 当前实验背景（已确认）

| 项 | 内容 |
|---|---|
| 任务 | T60（混响时间）盲估计 + 去噪辅助（多任务）|
| 模型 | CMGAN 改造的多任务框架，FourierKAN T60 回归头 |
| 数据集 | `T60_Dataset_v7_4s`，train 40k / eval 5,136 / test1-4 各 1,080 |
| 测试集划分 | test1=仿真+已见噪声，test2=真实+已见，test3=仿真+未见，test4=真实+未见 |
| 当前最优 | w_denoise（α=1.0, β=0.1）：四测试集均值 RMSE 96.41ms |

## 痛点确认

- **训练/验证/测试集中的真实 RIR 均偏少**（数量层面不足）。
- **更根本的痛点**：生产落地面对的是真实房间 RIR，当前模型主要在仿真域训练，存在仿真→真实的域迁移性能掉点风险。
- 需求焦点从"数量"修正为"**域迁移 + 真实多样性**"。

## 已排除方案（伪需求排除）

**❌ 直接用 GAN 生成"真实 RIR"**（陈宇瀚论文方法原样迁移）：
- 致命错配 1：T60 回归是**连续值标签任务**，GAN 生成的假 RIR **没有 ground-truth T60 标签**，无法用于监督训练。论文方法是分类任务（加同类样本即可），不适用于回归。
- 致命错配 2：GAN 生成的 RIR 若违反声学物理规律（能量衰减、直达声/混响结构），会注入错误分布，**反而拉低 T60 估计精度**。
- 结论：论文的 GAN 增广方法**不能直接迁移**到本任务。

## 用户假设澄清（已确认）

用户真实假设（非上轮理解）：
> "手上真实 RIR 就这么多（数量固定、不再增加），想在**已有真实 RIR 基础上做数据扩充**（augmentation 本意），让训练见到更多'真实样态'，从而真实 RIR 上估计更准。"

⚠️ 修正上轮误解：用户要的是"**从内部派生新样本**"，不是"从外部补公开集"。方向三（补数据）不算数。

## 关键技术约束（已从代码确认）

**T60 回归任务的标签铁律**：派生的每个新样本必须有正确 T60 标签。
- 代码事实（`dataset.py` L25-30）：T60 从目录名 `speech{id}_reverb_{T60}_{SNR}dB` 解析，**与 RIR 一一绑定**。
- 数据集存的是"已卷好的混合 wav"（`{name}.wav` + `{name}_denoised.wav`），**不是原始 RIR**。
- 推论：派生方法能否生效，取决于"能否把 RIR 从混合 wav 里分离出来重新卷绕"——这是决定性的前置条件。

## 派生方法安全分级（已梳理）

- 🟢 **零标签风险**：同一 RIR 重新搭配不同语音/噪声 → T60 不变。**最优解，但依赖能否拿到原始 RIR**。
- 🟢 **零标签风险**：SpecAugment（时频掩蔽）、增益扰动、随机窗裁剪。
- 🟡 **需验证标签**：物理参数插值生成新 RIR、CycleGAN 风格迁移。
- 🔴 **物理不成立**：GAN 直生成 RIR（已排除）。

## ✅ 方案方向定稿（已确认）

**角度 C：T60 引导的物理增广**。用户与分析师独立得出一致结论。

- 故事立意："标签可靠 + 物理可解释 + 任务定制"三位一体的 RIR 增广。

## 架构事实（已从代码确认，决定方案实现路径）

| 架构事实 | 对方案的影响 |
|---|---|
| T60Head 先 `mean(F)` 再对 T 取 avg/max/std 统计量 | T60 靠**时间维能量衰减形态**判断，与物理定义一致 → 物理整形模型可感知 ✅ |
| mag = √(real²+imag²)，输入 `[mag, real, imag]` 三通道 | 整形必须传导到 mag 时间包络；STFT 层直整形 mag 会破坏 phase 一致性 |
| 多任务去噪分支复用 backbone + 用 phase | 整形后样本必须 phase/mag 一致，否则污染去噪 target |
| T60Head 输出 sigmoid → 归一化 [0.1,1.5] | 标签重算后需过同套 T60Normalizer |

## ✅ 实现路径定稿（架构约束推导）

**走 RIR 波形层时域指数整形，不走 STFT 层整形**：
1. 取真实 RIR 波形 → 估计其衰减率 → 时域指数加权改变 T60
2. 解析公式（Schroeder/衰减率换算）重算 T60 标签 → **标签物理精确**
3. 整形后 RIR 重新卷绕 anechoic 语音 + 噪声 → STFT → mag/phase 天然一致
4. 新样本同时喂 T60 头和去噪头，多任务自动受益

## 域差量化（已确认，论文痛点证据）

w_denoise 模型四测试集 RMSE（来自 `evaluation_summary.json`）：

| 测试集 | RIR 类型 | 噪声 | RMSE (ms) |
|---|---|---|---|
| test1 | 仿真 | 已见 | 98.06 |
| test2 | **真实** | 已见 | **101.98** |
| test3 | 仿真 | 未见 | 91.91 |
| test4 | **真实** | 未见 | **93.70** |

**痛点证据**：
- test2（真实+已见）比 test1（仿真+已见）**差 3.92 ms**（+4%）
- 真实域整体表现弱于仿真域（test2 是四集中最差的）
- 这是论文 motivation 的直接数据：真实 RIR 上性能掉点 → 需要扩充真实多样性

## 方法学派别定位（已确认，论文写作关键）

本方法属于 **物理引导增广（physics-guided augmentation）**，与 GAN、SpecAugment 并列：
- **不是** GAN 派别，不需要对抗训练
- 用 GAN 反而坏事（标签不可靠），这正是本方法相对 GAN 的核心卖点
- 文献支撑充分（见下）

## 文献支撑（已查证）

- **Bryan (ICASSP 2020)** "Impulse Response Data Augmentation for Blind Room Acoustic Parameter Estimation" — 直接对标，做 RIR 增广估 RT60/DRR
- **StoRIR (Interspeech 2020)** — 可控 RT60 的随机 RIR 生成，用于数据增广
- **Schroeder 积分法** — T60 从 RIR 反推的经典物理方法（标签重算的理论基础）
- **SpecAugment (Park 2019)** — 时频掩蔽增广的代表性工作（作为 baseline 对比）
