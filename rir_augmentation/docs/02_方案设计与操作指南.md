## 一、理论准备（必须先搞懂的 4 件事）

### 1.1 T60 的物理定义

> **T60（混响时间）**：声源停止后，声能衰减 60 dB 所需的时间（秒）。

数学上，理想混响尾呈**指数衰减**：
$$
E(t) \propto e^{-t/\tau}, \quad T60 = 6\ln 10 \cdot \tau \approx 13.82 \cdot \tau
$$

**关键洞察**：T60 完全由衰减时间常数 τ 决定。**改 τ 就改 T60**——这就是物理增广的理论基础。

### 1.2 Schroeder 后向积分（标签重算的核心）

从一段 RIR 波形 $h(t)$ 反算 T60 的标准方法：

1. 平方：$h^2(t)$（能量）
2. **反向**累积积分：$L(t) = \int_t^{T} h^2(\tau)\,d\tau$
3. 取 dB：$10\log_{10} L(t)$
4. 在 0 ~ -60 dB 区间做线性回归，斜率对应 T60

> **这是你标签重算的"裁判"**：整形后的 RIR'，用 Schroeder 反算 T60'，与理论值对比。文档 3 验证的就是这一步。

参考实现（Python）：
```python
def schroeder_t60(h, sr, decay_db=60):
    """从 RIR 波形估 T60（Schroeder 后向积分 + 线性回归）"""
    h2 = h ** 2                          # 能量
    cumulative = np.cumsum(h2[::-1])[::-1]  # 反向积分
    db = 10 * np.log10(cumulative / cumulative.max() + 1e-12)
    # 在 0 ~ -decay_db 区间线性回归
    idx = np.where(db >= -decay_db)[0]
    t = idx / sr
    slope, intercept = np.polyfit(t, db[idx], 1)
    t60 = -60.0 / slope                  # 斜率为负
    return t60
```

### 1.3 时域指数整形（增广操作的核心）

给定真实 RIR $h(t)$，想把它变成目标 T60' 对应的 $h'(t)$：

1. 先用 Schroeder 积分估原 T60（τ_old）
2. 算目标 τ_new = T60' / 13.82
3. 构造整形包络：$w(t) = e^{-(1/\tau_{new} - 1/\tau_{old})t}$
4. 相乘：$h'(t) = h(t) \cdot w(t)$
5. 新标签 $T60'_{label}$ = 解析算出的 T60'（**零风险，物理精确**）

**为什么这成立**：$h(t)$ 本身已含 $e^{-t/\tau_{old}}$ 衰减，乘上修正因子后衰减率变成 $1/\tau_{new}$，T60 即被改写。这是受控的物理变换，不是黑箱。

⚠️ **注意**：整形只动**混响尾**（reverberation tail），直达声和早期反射（直接声后约 50-80ms）不能动——那是房间几何特征，动了就破坏真实性。详见 3.2 节。

### 1.4 RIR 卷绕语音（重新合成样本）

增广后的 RIR' 需要重新"应用"到语音上才能变成训练样本：

```
clean_anechoic.wav  ──┐
                      ├─ 卷积(convolve) ──► reverb.wav （纯混响，去噪 target）
RIR'.wav ────────────┘
                                        ┌─ + 加噪 ──► noisy_reverb.wav（模型输入）
noise.wav ─────────────────────────────┘          （按目标 SNR 缩放）
```

`torchaudio.functional.fftconvolve` + 能量匹配的噪声叠加即可。

## 三、物理增广操作流程（Pipeline 全貌）

### 3.1 总览

```
[原始真实 RIR] 约 4k 条
       │
       ▼
[步骤1] Schroeder 积分估原 T60 → 验证与 ACE 标注吻合
       │
       ▼
[步骤2] 时域指数整形（保守参数）
       │   目标 T60' ∈ [T60×0.85, T60×1.15]，每条派生 2-3 个
       │   只动混响尾，保留直达声 + 早期反射
       │
       ▼
[步骤3] Schroeder 反算验证 T60' 与理论值误差 < 5%（文档 3 守门）
       │
       ▼
[步骤4] RIR' × N 种 anechoic 语音 × M 种噪声（保守：N=2, M=2）
       │   按现有 SNR 分布 {-5,...,30} 叠加
       │
       ▼
[步骤5] 生成样本目录（命名格式同现有：speech{id}_reverb_{T60'}_{SNR}dB）
       │   含 {name}.wav（含噪混响）+ {name}_denoised.wav（纯混响 target）
       │
       ▼
[训练] 混入现有 train split，多任务训练（T60 + 去噪自动受益）
```

### 3.2 整形的关键约束（防踩坑）

| 约束 | 原因 | 处理方式 |
|---|---|---|
| **只动混响尾** | 直达声/早期反射是房间几何特征，动了破坏真实性 | 用 onset detection 定位直达声，前 ~50ms 不整形 |
| **T60 偏移保守** | 大偏移会让 RIR 落到 ACE 没覆盖的房间分布 | 起步 ±15%，后续消融加大 |
| **能量归一化** | 整形会改变总能量，需对齐训练分布 | 整形后做 peak/RMS 归一 |
| **避免极端 T60** | 你 stats 显示 T60≥1.2 本就稀疏，整形不要往更极端推 | 限制 T60' ∈ [0.1, 1.5]，与现有范围一致 |

### 3.3 增广规模（保守起步）

按你的"先保守"决策：

| 参数 | 保守值 | 含义 |
|---|---|---|
| 整形偏移 | ±15% | T60' = T60 × {0.85, 1.0, 1.15} |
| 每条 RIR 派生 | 2 个新 T60 | + 原始，共 3 倍 RIR |
| 重卷绕搭配 | 2 语音 × 2 噪声 | 每 RIR' 派生 4 个样本 |
| **总增广倍数** | 约 4k × 2 × 4 = 32k 新样本 | 真实质感样本从 4k → 36k |

> 这 32k 是"真实质感"样本，与现有仿真样本混合后，真实占比从 ~10% 提升到约 45%。后续消融可调。

## 四、代码集成姿势（改你现有代码的哪几个点）

### 4.1 不要改的东西（守住边界）

- ❌ **模型架构**（`models/`）：物理增广是数据侧，不动模型
- ❌ **训练循环**（`train_multitask.py`）：数据格式与现有一致，训练流程零改动
- ❌ **现有数据集**（`T60_Dataset_v7_4s/`）：不动，增广样本单独放

### 4.2 必须新建的文件

| 文件 | 职责 | 依赖 |
|---|---|---|
| `scripts/augment_rir.py` | 读真实 RIR → Schroeder 估 T60 → 指数整形 → 存 RIR' | numpy, soundfile |
| `scripts/resynthesize_samples.py` | RIR' × 语音 × 噪声 → 生成训练样本目录 | torchaudio |
| `scripts/verify_t60_label.py` | **文档 3 核心**：验证整形标签精度 | numpy, soundfile |

### 4.3 数据接入的两种姿势（选一种）

**姿势 A：离线生成，扩充 split 目录**（推荐，简单稳）
- 增广脚本一次性生成所有样本，存进 `train_aug/` 子目录
- `dataset.py` 的 `_scan_samples` 天然支持（它只扫目录），**零代码改动**
- 命名格式严格对齐：`{name}.wav` + `{name}_denoised.wav`
- 缺点：增广样本固定，不能动态调参数

**姿势 B：在线增广，Dataset 里动态生成**（灵活，复杂）
- 在 `CMGANT60MultiTaskDataset.__getitem__` 里动态整形 + 卷绕
- 可调倍数/强度，适合消融实验
- 缺点：改 Dataset 类，需保证可复现（固定随机种子）

> **建议**：先走姿势 A 跑通 baseline，论文消融阶段再用姿势 B 调参。文档 3 验证用姿势 A 的离线脚本最简单。

### 4.4 标签一致性的关键检查

你的 `dataset.py` 第 25-30 行从目录名解析 T60：
```python
t60 = float(parts[-2])  # speech{id}_reverb_{T60}_{SNR}dB
```

**增广样本命名必须让这个解析逻辑零修改就能用**：
- ✅ `speech_aug0001_reverb_0.347_5dB`（前缀改一下无妨，T60 在倒数第二段）
- ❌ `aug_0.347_5dB_speech0001`（解析逻辑会报错）

## 五、实验设计（撑起论文）

### 5.1 实验组（消融 + 对比）

| 组别 | 训练数据 | 目的 |
|---|---|---|
| **Baseline** | 现有 train（仿真为主 + 少量真实）| 对照基准 |
| **+重卷绕** | + 真实 RIR 重新卷绕（T60 不变）| 证明"多样性"贡献 |
| **+物理增广（本方法）** | + T60 引导整形 + 重卷绕 | **本方法**，证明"任务定制"贡献 |
| **+GAN 增广**（可选）| + GAN 生成 RIR | 反向证明 GAN 不行（可选，工作量大）|

**关键消融**：把"重卷绕"和"物理整形"拆开，证明你方法的核心贡献是**T60 引导整形**，不只是简单重卷绕。

### 5.2 评估重点

- **主指标**：test2/test4（真实 RIR）的 RMSE —— 这是痛点所在，提升要在这里体现
- **次指标**：四集均值、各 T60 bin 的误差（特别是稀疏的高 T60 区间）
- **域差量化**：test2-test1 的 RMSE 差值，看增广后是否缩小

### 5.3 论文故事线

1. **痛点**：真实域掉点（test2 101.98ms > test1 98.06ms）
2. **根因**：真实 RIR 少 → T60 网格稀疏（T60≥1.2 仅几十条）
3. **现有方法不足**：纯重卷绕不改 T60 网格；GAN 标签不可靠
4. **本方法**：物理引导增广，加密 T60 网格 + 标签精确
5. **继承思想**：受陈宇瀚"任务定制增广"启发，适配 T60 回归任务
6. **验证**：消融证明物理整形贡献，域差缩小
